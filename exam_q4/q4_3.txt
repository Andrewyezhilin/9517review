Q4.3

macro_rules! duration {
    ($n:literal h) => { std::time::Duration::from_secs($n * 60 * 60) };
    ($n:literal m) => { std::time::Duration::from_secs($n * 60) };
    ($n:literal s) => { std::time::Duration::from_secs($n) };
    ($n:literal h, $($rest:tt)+) => { duration![$n h] + duration![$($rest)+] };
    ($n:literal m, $($rest:tt)+) => { duration![$n m] + duration![$($rest)+] };
    ($n:literal s, $($rest:tt)+) => { duration![$n s] + duration![$($rest)+] };
}

The first three rules handle a single term: an integer literal followed by h,
m or s becomes Duration::from_secs with the right conversion (h -> n*3600,
m -> n*60, s -> n). The last three rules handle a term followed by a comma
and more terms: they convert the first term and recursively call duration!
on the rest, adding the Durations together (Duration implements Add).
For example duration![1 h, 30 m] expands to duration![1 h] + duration![30 m]
= from_secs(3600) + from_secs(1800) = 5400 seconds.

Checked against the examples:
duration![90 s]                  -> 90s
duration![1 h, 30 m]             -> 5400s
duration![2 h, 15 m, 30 s]       -> 8130s
duration![30 s, 1 m, 45 s, 15 s] -> 150s
